# CEA Appstore 0.3.0

- Accès manuel aux versions stables, bêta et dev dans les options avancées de chaque application.
- Indicateur de disponibilité des bêtas ; les versions expérimentales ne déclenchent pas de proposition automatique de mise à jour.
- Menus adaptés au thème sombre et orange, actions de tickets regroupées dans un menu compact.
- Signalement associé à l'application et à sa version, lien de suivi du ticket, gestion des erreurs GitHub.
- Installation confirmée avant enregistrement de la nouvelle version ; confirmation explicite avant remplacement par une préversion ou retour à une version antérieure.

Pour tester To-DoX dev : actualiser le catalogue, ouvrir Options avancées, choisir Développement puis installer explicitement la version souhaitée.
